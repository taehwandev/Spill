macOS menu bar utility

Spill

A compact control tray for crowded Mac menu bars, system status, pinned actions, AI tooling state, and fast window moves.

Download DMG Download ZIP

Requires macOS 14 or later. Open-source releases are published on GitHub.

What it does

One small trigger, one focused tray.

Status at a glance

CPU, memory, power, network, and Caffeine state stay compact and scannable.

Pinned actions

Keep useful menu bar actions close without depending on fragile spacer tricks.

Window moves

Move focused windows with quick actions and familiar keyboard shortcuts.

Install

Get the current release.

Download the DMG, drag Spill into Applications, then launch it from Applications. Accessibility permission is only needed for detected menu bar actions and window movement.

  1. Download the latest DMG.
  2. Move Spill to Applications.
  3. Open Spill and use the menu bar trigger.
