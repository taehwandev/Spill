Install

Get the current release.

Download the DMG, drag Spill into Applications, then launch it from Applications. If macOS says the app is damaged or should be moved to Trash, use the terminal install command to remove the quarantine flag.

/bin/bash -c "$(curl -fsSL https://thdev.app/Spill/install.sh)"

Already copied it to Applications? sudo xattr -dr com.apple.quarantine /Applications/Spill.app then open Spill again.

  1. Install Run the terminal installer or download the latest DMG.
  2. Keep it in Applications The installer copies Spill there automatically.
  3. Open from the menu bar Use the single Spill trigger to open and close the tray.
